# CONTRIBUTING

Thanks for helping out!

- Run `just check && just lint` before opening a pull request.
- Packages must be available for CentOS Stream 10 or EPEL 10.
- Changes to the shared Universal Blue setup hooks, `ujust` and other common tooling belong upstream in [projectbluefin/common](https://github.com/projectbluefin/common). This repo only consumes its desktop-agnostic `shared` half.
